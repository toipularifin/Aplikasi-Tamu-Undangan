Cara Hosting Gratis di GitHub Pages:

  1. Buat repository baru di github.com (misal: buku-tamu-hajatan, set ke Public).
  2. Klik Add file → Upload files, lalu unggah file index.html (dan README.md).
  3. Buka tab Settings → Pages pada repository tersebut.
  4. Pada bagian Branch, pilih main dan folder / (root), lalu klik Save.
  5. Tunggu 1-2 menit hingga muncul link aktif https://username.github.io/buku-tamu-hajatan/.
